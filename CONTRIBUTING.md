# Contributing to Cultivator

First off, thank you for considering contributing to the Cultivator! It's people like you that make open source such a great community.

## How Can I Contribute?

### Reporting Bugs
If you find a bug, please use the Bug Report template to file an issue. Be sure to include:
- A clear and descriptive title.
- Exact steps to reproduce the issue.
- Expected and actual behavior.
- Browser and OS information.

### Suggesting Enhancements
Have an idea for a new feature? We'd love to hear it! Use the Feature Request template to submit your idea. Describe the problem your feature solves and how it should work.

### Submitting a Pull Request
1. **Fork the repository** and create your branch from `main`.
2. **Setup your environment** by following the setup instructions in the `README.md`.
3. **Make your changes**. Keep your commits descriptive and focused on the issue at hand.
4. **Ensure tests and linting pass**. Run `npm run test` and `npm run lint`. Fix any linting errors before submitting.
5. **Update documentation** if you are changing how something works.
6. **Open a Pull Request** using the provided template, and link any related issues.

## Development Guidelines

- **Code Style:** We use ESLint and standard Angular guidelines. Run `npm run lint:fix` to auto-format your code.
- **Commit Messages:** Try to use clear, imperative commit messages (e.g., "Add user profile component" instead of "Added user profile").

Thank you for contributing!
